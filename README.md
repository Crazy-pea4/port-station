# Port Station · 服务控制台

一个极简的本地服务控制台:自动发现本机正在监听的端口,**智能区分「本地启动的开发服务」和「第三方应用」**(QQ、微信、Clash 等,路径位于 macOS `.app` 包内的进程),默认只展示前者。无需注册,关闭的服务自动从列表消失,不留记录;系统进程(root/守护进程)不会出现。

设计语言遵循 PlayStation 设计规范(`npx getdesign@latest add playstation` 的浅色模式):白底、PS 蓝药丸按钮(#0070d1)、8px 圆角卡片、轻字重(300)标题。已加 `darkreader-lock`,Dark Reader 等插件不会改写本站配色。

## 使用

```bash
npm install
npm run dev        # 开发模式,默认 http://localhost:3000
# 或
npm run build && npm start
```

- 每 5 秒自动扫描一次本机 TCP 监听端口(仅当前用户启动的进程,Port Station 自身除外)
- **智能分类**:通过 `ps` 查进程完整命令,路径含 `.app/` 的归为「第三方应用」(灰色标签,默认不展示,可切换查看),其余为「本地服务」(蓝色标签)
- 卡片展示:进程名、PID、端口、HTTP 状态码与响应耗时;悬浮进程名可看完整启动命令
- **打开**:有 HTTP 响应的服务可在浏览器直接打开;非 HTTP 服务置灰
- **关闭**:核对扫描时的 PID、属主和启动时间后发送 SIGTERM;1.5 秒后仅对仍存活的原进程发送 SIGKILL,不会强杀接替占用端口的新进程。旧卡片与进程身份不一致时要求刷新确认。
- **卡片图标**:左上角展示服务图标 —— HTTP 服务抓取其 favicon(含解析 `<link rel=icon>`),第三方应用从 `.app` 包内提取 icns 并转换;无图标的显示占位图形
- **智能标题**:图标右侧显示服务名称 —— 优先取进程工作目录下 package.json 的项目名,其次网页 `<title>`,第三方应用取 `.app` 的显示名,兜底进程名
- **关闭后驻留**:刚关闭的服务以「已关闭」状态留在页面中(仅本次会话内存,刷新即消失),保留了启动信息的可直接点「重新启动」拉起;无法恢复启动参数的显示「无法自动重启」+ 问号图标,悬停可见具体原因。重启信息的可恢复性:
  - `npm/pnpm/yarn/bun` 启动的基础项目脚本(例如 `npm run dev`):确认脚本仍存在后,以参数数组重新启动
  - Linux 可读取 `/proc` 中保留边界的 argv;含空格、空字符串、`--port=4000` 等参数均原样传递
  - macOS 的 `ps` 不保留 argv 边界。无法确认基础项目脚本、或脚本带额外参数时,不猜测参数,显示无法恢复的原因
  - 重启继承控制台的环境变量,不会恢复原终端的临时环境变量。依赖这些变量的服务请回到原终端启动
  - 关闭成功后只向浏览器签发记录 ID;配方保存在服务端内存,有效期 24 小时,最多保留 128 条。控制台重启后失效
  - 慢启动期间重复请求不会再次拉起进程;启动失败会显示原因与日志位置,日志保存在系统临时目录下独立的 `port-station-*` 目录中
- 不关心的端口点卡片右上角 × 隐藏,记录在浏览器 localStorage,可随时恢复
- 支持按端口、进程名、PID 搜索

## 技术栈

- Next.js 16(App Router)+ React 19 + Tailwind CSS v4
- 端口扫描:`lsof -nP -iTCP -sTCP:LISTEN -F pcnL`,按登录用户过滤 + 系统进程黑名单
- 分类:`ps -o pid=,command=` 取完整命令路径,`.app/` 包内进程识别为 GUI 应用
- 重启信息:关闭前重新捕获可确认的脚本或原始 argv + 工作目录,以 detached 方式拉起;`/api/services/start` 只接受服务端记录 ID,不接受客户端命令,不通过 shell 拼接启动参数
- 关闭进程:`process.kill`,内置自身保护(不会杀掉 Port Station 自己)
- 无数据库、无外部依赖服务,纯本地运行

## 本机访问与验证

开发和生产命令均只监听 `127.0.0.1`。API 校验本机 Host 和请求 Origin;修改操作还需要由本机列表接口取得的会话令牌及 JSON 请求体。不支持通过局域网或反向代理开放进程控制接口。

字体使用本机 Inter/Roboto 或系统字体回退,构建无需下载 Google Fonts。

```bash
npm run typecheck
npm run lint
npm test                # 隔离回归测试;包含短暂运行、自动退出的测试子进程
npm run build
npm run test:smoke      # 构建后执行;创建并清理临时测试项目,验证扫描、关闭、重启
```

若受限环境阻止 Turbopack 创建内部通信端口,可用 `npm run build -- --webpack` 验证生产构建。真实流程测试需要允许读取本机进程信息并监听本机端口,只会关闭脚本创建的临时测试服务。
